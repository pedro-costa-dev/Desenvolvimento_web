aula · unidades de medida em css

vh não é %. E isso muda o layout inteiro.

Duas formas de dizer "ocupe a altura toda" que parecem sinônimas — mas uma depende do elemento pai e a outra depende só da janela do navegador. Essa diferença é o que decide se uma página rola ou não.

vh, vw — relativo à viewport (a janela) % — relativo ao elemento pai

O que observar: o bloco em % muda de tamanho junto com o pai — ele é uma fração do pai. O bloco em vh fica travado no mesmo tamanho em pixels, porque 50vh é sempre metade da altura da janela do navegador, não do pai. É por isso que height: 100% só funciona se o pai já tiver uma altura definida — e height: 100vh funciona sempre, porque a viewport sempre tem altura.

02 · duas abordagens de página

Exemplo A: sem rolagem — Exemplo B: com rolagem

Mesma estrutura de conteúdo, duas regras diferentes no html, body. Repare no que acontece com o conteúdo que não cabe.

Exemplo A

sem rolagem 
html, body {
  height: 100vh;
  margin: 0;
  overflow: hidden;
}

Exemplo B

com rolagem 
html, body {
  min-height: 100vh;
  margin: 0;
}
.conteudo {
  /* mais alto que a tela */
}
No Exemplo A, height: 100vh trava o body no tamanho exato da janela, e overflow: hidden corta qualquer coisa que ultrapasse isso — o excesso simplesmente some. No Exemplo B, min-height: 100vh garante que o body pelo menos preencha a tela, mas deixa ele crescer se o conteúdo for maior — e sem overflow: hidden, o navegador cria a barra de rolagem naturalmente.

04 · referência rápida

Quando usar cada um

propriedadeo que fazquando usar
height: 100vh Trava a altura no tamanho exato da janela do navegador, sempre. Telas de abertura, landing pages de uma tela só, seções "hero" que devem ocupar a tela inteira.
height: 100% Ocupa 100% da altura do elemento pai — só funciona se o pai tiver altura definida. Layouts aninhados, onde o pai já controla o tamanho (ex: um card dentro de uma grade).
min-height: 100vh Garante pelo menos a altura da tela, mas permite crescer além disso. Páginas de conteúdo normais (blog, formulário, artigo) que devem preencher a tela mesmo com pouco texto, mas rolar se tiverem muito.
overflow: hidden Esconde qualquer conteúdo que ultrapasse os limites do elemento. Apps de tela única (dashboards, jogos, players) onde a rolagem quebraria o layout.
overflow: auto Mostra barra de rolagem só quando o conteúdo excede o espaço disponível. Comportamento padrão recomendado para a maioria das páginas de conteúdo.
box-sizing: border-box Inclui padding e borda dentro da largura/altura declarada, em vez de somar por fora. Praticamente sempre — evita que padding "estoure" um height: 100vh.

05 · armadilhas comuns

Onde os alunos costumam travar

"Coloquei height: 100% e não fez nada"

% só funciona em relação a um pai com altura definida. Se html e body não tiverem altura declarada, a cadeia de porcentagens não tem de onde puxar valor — e o elemento colapsa.

"100vh no celular deixa uma faixa sobrando"

Em navegadores móveis, a barra de endereço aparece e some, e 100vh é calculado sobre a altura máxima possível — não a visível no momento. Para esse caso, as unidades mais novas 100dvh (dynamic viewport height) resolvem melhor, quando o suporte do navegador permitir.

"Coloquei overflow: hidden e sumiu conteúdo importante"

overflow: hidden não avisa quando corta algo — ele simplesmente esconde. É uma ferramenta de layout de tela única, não algo para usar "por garantia" em páginas de conteúdo comuns.

"Meu padding estourou a altura da tela"

Sem box-sizing: border-box, o padding se soma à altura declarada em vez de ser descontado dela. Um height: 100vh com padding pode passar da tela sem que a regra pareça errada.

06 · o par que mais confunde

height: 100vh + overflow: auto vs min-height: 100vh

Os dois "resolvem" uma página curta do mesmo jeito. A diferença só aparece quando o conteúdo é maior que a tela — e mesmo assim, é sobre onde a rolagem acontece, não se ela acontece.

height: 100vh + overflow: auto

rolagem interna 
html {
  height: 100vh;
  overflow: hidden;
}
body {
  height: 100vh;
  margin: 0;
  overflow: auto;
}

min-height: 100vh

rolagem da página 
html, body {
  min-height: 100vh;
  margin: 0;
}
Repare na borda colorida ao redor do conteúdo dentro de cada exemplo — ela marca a caixa do body. À esquerda, essa borda não se mexe: ela fecha exatamente no tamanho da tela, e é só o conteúdo por dentro dela que rola — como um documento dentro de uma janela de tamanho fixo. À direita, a borda acompanha o conteúdo e continua além da tela: o body realmente cresceu, e quem rola é a página toda.
Pegadinha real: esse comportamento de "caixa travada com rolagem própria" só acontece porque o exemplo da esquerda também define overflow: hidden no html. Se você colocar overflow: auto só no body e deixar o html sem overflow declarado, o navegador "propaga" essa rolagem para a página inteira — e o resultado acaba idêntico ao min-height: 100vh. Isso pega muita gente de surpresa: "coloquei overflow no body e não fez nada diferente".
