# Ap1 Dev web 2026.2 

# Voce irá desenvolver um site escolhendo um negócio: uma loja, restaurante, academia. Você escolhe seu tema. Esse site deve ter os seguintes requisitos:

## 1. Três páginas html interligadas (index, serviços e contato) e estilizadas com css com a abordagem desktop first (1pt).
## 2. Um header com um logo a partir de uma imagem local e um nav comum às 3 páginas (1pt).
## 3. Pelo menos 1 imagem local no main do index.html e do servicos.html. Na página de serviços deve ter ao menos 2 seções no main em uma única coluna (0.5pt).
## 4. Um footer comum à todas as páginas, com copy rights e uma estrutura de navegação para redes sociais (3 pelo menos) usando ícones do fontawesome (1pt).
## 5. A página contato.html possui um formulário html com os inputs de nome, email e submit com labels pareadas e alinhado ao centro da página. Validação básica do html para esses campos (1pt).
## 6. O header deve ser responsivo e em desktops ter à esquerda o logo e a razão social, e à direita o nav em uma mesma linha e alinhados no centro do contra-eixo flex. Em mobile (celulares e phablets) deve estar em coluna com os elementos centralizados no contra-eixo flex em relação ao header (2pt).
## 7. O main do index deve ter ao menos uma section com 3 colunas em desktops e uma coluna em mobile (1.5 pts).
## 8. Use boas práticas de semântica para elementos html e acesibilidade (1pt).
## 9. CSS em arquivo externo e devidamente ligado às páginas do site (0.5).
## 10. Todas as imagens do projeto locais e organizadas em subpasta imagens(0.5).
